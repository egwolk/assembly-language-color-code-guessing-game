# ASSEMBLY LANGUAGE COLOR CODE GUESSING GAME
## CMARCH1 Final Project

## How to run
- Place project folder or just the G5.asm in your C drive.
- Mount folder in DOSBOX with: 
```
MOUNT X C:/Path
X:
```
- assemble in DOSBOX: `tasm g5`
- Build EXE file with `tlink g5`
- run `g5`
